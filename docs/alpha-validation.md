补充检查：Tracking Off 立即影响所有已打开标签页；服务 Worker 停止/恢复后延续 Session；无活动 90 秒暂停阅读、超过三分钟重开 Session；跨本地午夜；导入相同 JSON 两次不增加记录；不采集用户主页/私信；只在 Debug Mode 出现页面面板。

误差边界：非正常关闭最坏损失最后 15 秒的阅读 checkpoint。Observer 与主线程调度存在浏览器时序误差；统计中的跨日曝光指标按曝光时长占比分配，Session 和阅读时长按有效时间段精确切分。
